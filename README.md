# maya-arabic

Maya's Arabic exam prep (7th grade). Live at https://cwinter1.github.io/maya-arabic/

- `index.html` – the game: 9 missions (lesson 1: letters, words, digits, a/i vowels and hamza, "my"; notebook: tens in words, u + sukun, extra words, forms of ya), scoring, sound
- `notes.html` – summary of the handwritten course notes
- `tests/smoke.js` – Playwright smoke test (`npm install --no-save playwright && node tests/smoke.js`; set `SMOKE_URL` to test the live site)
